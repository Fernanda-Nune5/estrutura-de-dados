# estratura-de-dados
Repositório com conteúdos, exemplos e exercícios sobre Estruturas de Dados, abordando conceitos como vetores, listas, pilhas, filas, árvores, grafos e structs na linguagem C.

WAR Estruturado em C

Projetos desenvolvidos durante os estudos de Estruturas de Dados e Programação em C, simulando partes do jogo WAR com foco em lógica, ponteiros, structs, memória dinâmica e modularização.
